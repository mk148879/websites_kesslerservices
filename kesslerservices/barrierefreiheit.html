Accessibility

WCAG 2.2 AA

This static offline website has been designed and checked against the relevant WCAG 2.2 Level AA requirements.

Status

Page structure, navigation, color contrast, focus states, keyboard interaction and animations have been aligned with WCAG 2.2 AA. The site contains no forms, no audio or video content and no external tracking or script dependencies.

Implementation

  • Semantic HTML structure with header, navigation, main and footer.
  • Skip link for direct access to the main content.
  • Visible focus states for links and buttons.
  • Sufficient color contrast for text, links and controls.
  • Reduced motion support when enabled in system settings.
  • Alternative text or decorative marking for images and graphics.

Contact

Accessibility barriers or display issues can be reported by e-mail to info@kessler-services.ch.

Status Date

Last reviewed: June 2026. This statement refers to the locally delivered HTML version of this website.
